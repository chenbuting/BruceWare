# 模块目录

每个功能一个文件夹。底座会扫描这里的 `manifest.yaml`，列到网页「模块」页和侧栏。

| 文件夹 | 名称 | 说明 |
|--------|------|------|
| `help` | 帮助 | 公共说明 |
| `hub` | 模块 | 开关、固定侧栏 |
| `portal` | 网站入口 | 收藏网站 |
| `resume` | 简历 | 保存、分析、模拟面试 |
| `wardrobe` | 衣橱 | 衣服图、试穿和搭配 |
| `files` | 文件 | 本机或服务器文件夹 |
| `kb` | 知识库 | 整理资料、提问对证 |
| `data` | 数据 | 看和改库里的表 |

## 以后怎么加

```
modules/
  功能名/
    manifest.yaml    模块说明（底座靠它发现你）
    ...              该功能自己的说明
```

实现仍放在 `apps/`。新模块如果加了 `apps/api/app/<名>/models.py`，启动会自动建表，「数据」里会自动出现。

`manifest.yaml` 最少写：

```yaml
id: portal
name: 网站入口
description: 收藏常用网站
version: 0.1.0
```
