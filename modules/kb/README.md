# 知识库

个人资料库。侧栏会出现「知识库」。给人核对资料，不是给助手调工具。

可以建多个库，每个库用文件夹和标签整理。默认只查当前库。

**已接**

- 上传、预览：PDF / 图片 / 文本 / CSV / Excel（`.xlsx` `.xls`）
- 提问：回答或核对清单；严格出处或宽松概述
- 检索：关键词 + 向量；问句会按语意改写；相邻段一起带
- 出处：【确凿】【推断】【缺失】【冲突】；只用到的才列出；清单不下合不合格
- 向量状态：未向量 / 已向量 / 待重算；向量 Key 可单独填
- 可选 Wiki：给人看，不进检索；「跟着提问更新」默认关
- 可选识图：抽图、看图或本地 OCR；图不进向量
- 多段对话可同时问；备份带上知识和文件

接口和页面：`apps/api/app/kb`、`apps/web/src/pages/KbPage.tsx`。这个文件夹用 `manifest.yaml` 让底座发现模块。
