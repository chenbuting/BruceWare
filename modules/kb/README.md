# 知识库

个人资料库。侧栏会出现「知识库」。

可以建多个库，每个库里用文件夹和标签整理资料，预览 PDF / 图片 / 文本。

当前接口和页面还挂在底座里（规划：`apps/api/app/kb`、`apps/web/src/pages/KbPage.tsx`）。这个文件夹用 `manifest.yaml` 让底座发现模块。
