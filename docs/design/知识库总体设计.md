# 知识库总体设计

通用个人知识库，不绑招标。可建多个库。先整理再问。四层彼此独立，可开关。

## 一句话

多库隔开。对着本轮抽出的原文对答案。Wiki 给人看、不进检索。向量帮换说法找到原文。

## 现状（2026-09）

一到四期已经落地。知识库是给人核对的，不要做成 Agent（不跨库、不调工具、不上 Graph RAG / LangChain）。

另外有独立模块「数据」管表的增删改查，不替代本页提问。

## 要解决什么

- 资料要能分类、换电脑还能认
- 能问，对错能对回本轮原文
- 摘要可沉淀，但不是每次必走，关掉就不养
- 路径可收窄，也可关，改走整库检索

## 四层（彼此独立）

| 层 | 作用 | 开关 |
|---|---|---|
| 知识库 | 最大隔间，避免串台 | 默认只查当前库；跨库不做 |
| 路径 / 标签 | 缩小到某个文件夹、标签 | 有范围才收 |
| Wiki 摘要 | 沉淀笔记、给人看 | 默认关。不当证据 |
| 向量 + 原文 | 换说法找到原文，带出处 | 默认本机逐条比。可选 Milvus，见对接设计，默认关闭。向量失败则只走关键词 |

Wiki 关了，路径照常。路径关了，仍在当前库里检索。

常用组合：

1. 开路径 + 关 Wiki（默认就合适）
2. 路径、Wiki 都关，只检索
3. 都开：先收窄，摘要给人看，再检索原文

## 流程

资料从上传到回答分成七步。后一步只用前一步的结果。只改知识库内部，衣橱、文件、网盘等其他模块不动。

| 步 | 做什么 | 改了它，后面要不要重做 |
|---|---|---|
| 1. 入库 | 上传或导入。原件落盘，记下库、文件夹、标签 | 原件换了，从解析重做 |
| 2. 解析 | 抽出正文、表格格子、图片。按文件类型可选：Word 段落或表格，PDF 指定页，表格指定表或列，文本指定编码。抽出后还可以再跑一段脚本 | 换了方式，要点「只解析这一份」才重做 |
| 3. 清洗 | 默认收成一行。按完整性、唯一性、规范性、有效性、安全性分组。自定义规则可选怎么认、怎么处理，也可以写一段只改正文的脚本。做完列出每一类过了几条、挡了几条 | 换了方式，要点「只清洗这一份」才重做 |
| 4. 切片 | 默认 400 字一段、重叠 60、最多 40 段。这一份还可按段落切，或整篇一段 | 换了切法，要点「只切片这一份」才重做 |
| 5. 向量 | 默认给切片算数字，存在本机。这一份可以改成只按关键词找。填了 Milvus 再同步 | 只换向量模型时，不用重新解析和清洗 |
| 6. 检索 | 当前库里关键词加向量。没开 Milvus、没同步齐或连不上，就本机逐条比 | 不改已存的字和数字 |
| 7. 回答 | 问句可改写。结论带上本轮原文和出处 | 不改资料 |

点开某一份资料，解析、清洗、切片、向量各是一块。点开哪一块只做那一块，后面的不会自动跟着变。解析会按这份文件的类型给出抽法，也可以再写一段脚本。清洗按数仓那几类分组，做完能看到每一类过了几条、挡了几条。自定义规则可以按包含、开头、结尾或正则来换成、删掉或只留符合的行，也可以再写一段脚本。没点过的资料仍用原来的做法。

Wiki 开着才可选写摘要，摘要不进这七步。

**提问时**

当前库 → 可收窄文件夹 → 问句按语意改写 → 检索 → 结论 + 本轮原文 + 出处。

## 回不回原文

不写死关键字对照表，按事情类别判断。长期规则 + 当次覆盖。默认带出处。

- 严格：只信本轮原文，禁止【推断】
- 宽松：可以【推断】，须标明
- 同一事实多种写法标【冲突】，不同名目分开写
- 核对清单只标命中 / 未命中 / 冲突，不下合不合格

## Wiki

- 默认可关。关掉没有胀、假、要养的问题
- 开了：点了才沉淀；「跟着提问更新」默认关
- 严格模式摘要不当证据

## 图文

已做：抽图、可选识图（看图或本地 OCR）、出处可带图。图不进向量。材料组不做。

## 表格

CSV 按 UTF-8，不行再按国标。Excel（`.xlsx` `.xls`）抽格子文字再向量化。预览显示抽出来的字，不把压缩包当正文。

## 文件放哪

- 物理位置：`根目录/BruceWare/kb/{库id}/`（未「跟着走」时用程序 `data/kb/`）
- 库里只存相对路径，不写盘符
- 文件柜里已有的：只引用、不拷第二份（字段占位，尚未做）
- 整包拷走、向量模型不变：不重算向量
- 新电脑要再指定一次根目录

## 短处怎么收

- Wiki 要养：默认关；开了才写
- 漏段：改写 + 相邻段，不加助手多跳
- 办事（搜网、改文件、写标书）：不在本库做
- 懒得写规则：默认带出处 + 两个预设

## 分期

| 期 | 做什么 | 状态 |
|---|---|---|
| 一期 | 多库、上传、文件夹、标签、预览 | 已做 |
| 二期 | 对着当前库提问，带出处 | 已做 |
| 三期 | 可选 Wiki + 白话规则 + 当次覆盖 | 已做 |
| 四期 | 向量 + 图文检索 | 已做 |
| 之后 | 表格抽字、冲突口径、对话、向量状态、备份带文件 | 已做 |

## 先不做

自动分目录、多机同步、跨库搜、招标专活、给助手调工具、Graph RAG / LangChain、图进向量、材料组、改衣橱和文件柜已有逻辑。
