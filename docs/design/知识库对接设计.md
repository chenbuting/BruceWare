# 知识库对接设计

通用个人知识库。投标文件只拿来试查得准不准，不把库做成招标专用。

资料、切片、出处都在本机。要变聪明的那几步，对接兼容 OpenAI 的接口。哪一路没填，就退回这一路的本机做法，整个库仍能用。

不另做 Unstructured、本机大模型。Milvus 可选，默认不用，代码已预备，见下文。总体口径仍以 [知识库总体设计](./知识库总体设计.md) 为准。Agent 仍见 [Agent模块计划](./Agent模块计划.md)，不进提问页。

## 两半怎么分

| 一半 | 放哪 | 断网或没填 Key |
|---|---|---|
| 原件、库、文件夹、标签、切片、出处 | 本机 SQLite 和磁盘 | 照常 |
| 改写问句、写成回答、算向量、看图 | 设置里的接口 | 这一步跳过，用下面的退回 |

设置存在本机 `data/app-settings.json` 的 `llm` 里。对话、向量、识图可以填不同的地址和 Key。

## 现在就能接的三路

| 路 | 设置项 | 调用 | 没填或失败时 |
|---|---|---|---|
| 对话 | `base_url`、`api_key`、`model` | `POST …/chat/completions` | 只列出命中原文，不写回答 |
| 向量 | `embedding_base_url`、`embedding_api_key`、`embedding_model` | `POST …/embeddings` | 只用关键词。向量地址或 Key 空着时，沿用对话那套 |
| 识图 | 库规则里选「看图」 | 仍走对话接口，多带一张图 | 库规则改选「本地 OCR」，或关掉识图 |

向量模型名会记在每段上。设置里一换模型，旧数字标成待重算，不算混用。

接口约定就是现在的 `apps/api/app/core/ai.py`：地址可指向官方，也可指向中转。知识库不直接散落各处请求。

## 提问时接口怎么插进去

1. 本机按当前库、文件夹、标签圈定范围。
2. 配了对话接口，才把问句改写成更清楚的查找句。失败就用原问句。
3. 本机关键词始终查。
4. 配了向量接口，才把问句变成数字。开了 Milvus 就让它找相近段；没开、连不上或失败，就和本机切片数字逐条比。向量接口本身失败就当这次没有向量。
5. 两路结果合并，带上相邻段、对得上的图。
6. 配了对话接口，才把原文写成回答，并标【确凿】【推断】【缺失】【冲突】。没配就只给原文和出处。
7. 数字和原话以命中原文为准。点出处打开本机原件。

识图不在提问时自动跑。库规则打开后，由人点「识图」。认出来的字写回本机，之后关键词能搜到。

## 讨论里的零件

| 零件 | 怎么接 |
|---|---|
| 向量数据库 | 默认存在本机 `kb_chunks.embedding`，提问逐条比。可选 Milvus，不填就不用。代码已预备，默认关闭 |
| 加载 | 本机 `extract.py`。不把文件交给拆文档的云服务 |
| 切片 | 本机约 400 字一段，重叠约 60 字 |
| 嵌入 | 向量这一路 API |
| 检索 | 本机关键词 + 可选向量 |
| 重排序 | 先不做。要做时也是再加一路 API，失败就用现在的合并结果 |
| Agent | 以后的模块只读调用现在的检索，不另接一套库 |
| 图谱 | 不做 |
| 元数据 | 库、文件夹、标签、哈希、解析状态，全在本机 |

## 可选 Milvus

默认不用。向量数字仍写在本机 `kb_chunks.embedding`，提问时在当前库里逐条算相似度。不填 Milvus，行为和现在一样。

设置另开这一路，存在 `data/app-settings.json`。

| 设置项 | 作用 | 空着时 |
|---|---|---|
| `milvus_uri` | Milvus 地址 | 不用 Milvus |
| `milvus_token` | 连接口令 | 按地址直连 |
| `milvus_collection` | 集合名 | 用默认名 `kb_chunks` |

规矩：

- 本机这份数字始终要写。备份、换模型、Milvus 连不上，都靠它。
- 开了之后，上传、改一段、整份重算、删除资料，本机写完再同步到 Milvus。同步失败只提示，不让保存失败。
- 提问：Milvus 可用就用它在当前库里找相近段；失败或没开，就退回本机逐条比。关键词照常查。
- 只查当前库。库 id、资料 id、段号要一起存进 Milvus，方便删和过滤。
- 换向量模型后，旧集合不能混用。集合名后面带上维度，查找再按 `embedding_profile` 过滤。
- 索引用 Milvus 自己的 AUTOINDEX，设置里不选算法。
- 还没同步齐的库，提问仍走本机逐条比。
- 代码已预备，默认关闭。要用时再安装 `pymilvus`，并在设置里填写地址。

## 以后再加一路接口的规矩

- 单独的地址、Key、模型名，不塞进别的路。
- 调用仍收进 `app/core/ai.py`，知识库只问「这路现在能不能用」。
- 失败要退回，不能让提问整个报错。
- 换模型要能看出旧结果失效。向量已经是这样做的。

- 资料可停用。提问跳过，原件和向量还在，列表里点恢复即可。
