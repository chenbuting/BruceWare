# 知识库详细设计

对应 [总体设计](./知识库总体设计.md)。本文写清一期落地和后期占位。一期已按本文落地。

## 1. 一期范围

做：多个库、上传、文件夹、标签、列表、预览。没配 AI 也能用。

不做：提问、Wiki 页面、向量、OCR、自动分目录、从文件柜引用（字段先留）、跨库搜、备份导出带 kb。

不改：衣橱、文件柜已有逻辑。

## 2. 页面

新模块「知识库」，路由 `/m/kb`。

- 顶栏：切换 / 新建 / 改名 / 删除库
- 左：当前库文件夹树（可新建、重命名、删除）
- 中：当前文件夹下的文件，可按名称、标签筛
- 右：预览（PDF / 图片 / 文本，复用文件柜的类型判断）
- 上传到「当前库 + 当前文件夹」；标签手写
- 重复文件（哈希相同）提示，不默默存两份
- 首次进入自动建一个「默认」库

## 3. 物理路径

```
{app_data_dir}/kb/{library_id}/...文件相对路径
```

`app_data_dir` 与衣橱、数据库相同：设置了「跟着走」则是 `根目录/BruceWare`，否则是程序 `data/`。

库表只存相对 `kb/{library_id}/` 的路径，不写盘符。

## 4. 表结构

### 4.1 kb_libraries

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| name | 库名 | 用 |
| description | 说明 | 用 |
| policy_json | 白话规则、是否开 Wiki、是否关路径 | 占位，可空 |
| extra | 扩展袋 | 占位 |

### 4.2 kb_folders

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| library_id | 所属库 | 用 |
| parent_id | 父文件夹，空为库根下 | 用 |
| name | 名称 | 用 |

逻辑路径由父子关系拼出，不另存绝对路径。

### 4.3 kb_documents

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| library_id | 所属库 | 用 |
| folder_id | 所属文件夹，可空=库根 | 用 |
| title | 显示名 | 用 |
| file_name | 原始文件名 | 用 |
| rel_path | 相对 kb/库id 的路径 | 用 |
| source | `upload` / `files_ref` | 一期只写 upload |
| tags | 标签，逗号或 JSON 列表 | 用 |
| file_hash | 内容哈希，查重 | 用 |
| parse_status | `ready` / `no_text` / `failed` / `pending` | 一期：能预览即 ready，否则按类型标 |
| mime_or_kind | pdf / image / text / other | 用 |
| evidence_level | `可概述` / `须出处` / `须原图` | 占位，默认须出处 |
| files_ref | 文件柜引用信息 | 占位 |
| wiki_json | 摘要、是否过期 | 占位 |
| embedding_profile | 向量模型名、维度 | 占位 |
| extra | 扩展袋 | 占位 |
| created_at / updated_at | 时间 | 用 |

不建 Wiki 表、不建向量表。三期、四期再加。

## 5. 接口（一期）

前缀 `/api/v1/kb`。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/libraries` | 库列表 |
| POST | `/libraries` | 新建库 |
| PUT | `/libraries/{id}` | 改名/说明 |
| DELETE | `/libraries/{id}` | 删库（同时删文件夹、记录和磁盘文件） |
| GET | `/libraries/{id}/folders` | 文件夹树 |
| POST | `/libraries/{id}/folders` | 新建文件夹 |
| PUT | `/folders/{id}` | 重命名 |
| DELETE | `/folders/{id}` | 删除（空文件夹或连文件策略：一期仅空文件夹可删，或二次确认后连文件删） |
| GET | `/libraries/{id}/documents` | 列表，可按 folder_id、关键词、标签 |
| POST | `/libraries/{id}/documents` | 上传（multipart） |
| GET | `/documents/{id}` | 详情 |
| PUT | `/documents/{id}` | 改标题、标签、移动文件夹 |
| DELETE | `/documents/{id}` | 删除记录和文件 |
| GET | `/documents/{id}/file` | 预览/下载原件 |

查重：同库同哈希已存在则返回提示，由前端决定取消或仍要另存。

## 7. 后期怎么接（一期只占位）

| 口 | 一期 | 以后 |
|---|---|---|
| source | 只 upload | files_ref 引用文件柜 / SFTP |
| parse_status | 能预览即 ready | OCR、加密 PDF |
| search | 文件名、标签 | 统一 `search(问句, 过滤)`，再插向量、Wiki |
| policy_json | 空 | 开没开 Wiki、关没关路径、白话规则 |
| wiki_json | 空 | 摘要、过期、回写 |
| embedding_profile | 空 | 模型名+维度，搬家不重算 |
| extra | 空 | 页码、材料组等 |

提问默认：当前库；路径按开关；Wiki 按开关；关路径则整库向量。

## 8. 删除与搬家

- 删库：库记录、子文件夹、文档记录、该库磁盘目录一起删
- 搬家：文件和库都在 `BruceWare` 包内，相对路径有效
- 备份导出带 kb：二期再接入现有 backup，一期不改备份模块
