# 知识库详细设计

对应 [总体设计](./知识库总体设计.md)。本文写清一期落地和后期占位。一、二、三期已按本文落地。

## 1. 一期范围

做：多个库、上传、文件夹、标签、列表、预览。没配 AI 也能用。

不做：Wiki 页面、向量、OCR、自动分目录、从文件柜引用（字段先留）、跨库搜。提问见下一节。

不改：衣橱、文件柜已有逻辑。

### 1.1 二期范围

做：对着当前库提问。先抽 txt/md/docx/pdf 正文，按关键词打分，召回若干段原文。配了 AI 就写成回答并标出处；没配 Key 只列出命中资料。点了文件夹可勾「只搜当前文件夹」（含子目录）。

不做：向量、图文检索。Wiki 见下一节。

### 1.2 三期范围

做：库规则（严格出处 / 宽松概述 + 一句白话规则）、提问当次覆盖、可选 Wiki（默认关）。

Wiki 存在资料自己的 `wiki_json`，不另建表。找原文仍是关键词，摘要不参与检索。严格出处时摘要不进回答依据。单条最多 400 字，超了按整句截。不限条数，管理库分页看（每页 50）。原文变了只标可能过期。删资料同步删摘要。可选「跟着提问更新」：问完只改有出处的资料，最多 5 份；没出处不改也不提示。

不做：独立 Wiki 页面、自动写全库摘要。向量见下一节。

### 1.3 四期范围（第一刀）

做：文本向量。上传或提问时把正文切段、调用现有 AI 的向量接口，和关键词一起找原文。换说法也能对上。向量接口不可用时仍走关键词。

不做这刀：图文、OCR、出原图。设置页不改，向量模型名先用 `embedding_model`（默认 `text-embedding-3-small`）。

### 1.4 四期图文（第一刀）

做：PDF / docx 抽图，独立图片当一张图。图存 `kb/{库id}/assets/{资料id}/`，表 `kb_assets`。图名写进检索正文。提问只带和问句对得上的图，对不上不带。

不做这刀：识图 / OCR、须原图、材料组。

### 1.5 四期识图（第一刀）

做：库规则加「开启识图」，默认关。开了才允许认图。上传只抽图、不自动识图；由列表「全部识图」或预览单张「识图」来认。抽图不设张数上限，已抽过的只补缺的。提问只带和问句对得上的图。认完一张就填上字。认失败的下次不再自动重试，单张可再点。预览里可看、改、保存这些字，保存后重拼检索。

不做这刀：须原图、材料组、图进向量。设置页不改。

## 2. 页面

新模块「知识库」，路由 `/m/kb`。

- 顶栏：切换 / 新建 / 改名 / 删除库
- 左：当前库文件夹树（可新建、重命名、删除）
- 中：当前文件夹下的文件，可按名称、标签筛
- 右：预览（PDF / 图片 / 文本，复用文件柜的类型判断）
- 上传到「当前库 + 当前文件夹」；标签手写
- 重复文件（哈希相同）提示，不默默存两份
- 首次进入自动建一个「默认」库
- 顶栏下可提问；出处可点开右侧预览
- 提问可当次覆盖回答风格；管理库里设规则和 Wiki
- 预览里可写摘要（库开了 Wiki 才行）

## 3. 物理路径

```
{app_data_dir}/kb/{library_id}/...文件相对路径
{app_data_dir}/kb/{library_id}/assets/{document_id}/...抽出的图
```

`app_data_dir` 与衣橱、数据库相同：设置了「跟着走」则是 `根目录/BruceWare`，否则是程序 `data/`。

库表只存相对 `kb/{library_id}/` 的路径，不写盘符。

## 4. 表结构

### 4.1 kb_libraries

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| name | 库名 | 用 |
| description | 说明 | 用 |
| policy_json | 白话规则、是否开 Wiki、是否关路径 | 占位，可空 |
| extra | 扩展袋 | 占位 |

### 4.2 kb_folders

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| library_id | 所属库 | 用 |
| parent_id | 父文件夹，空为库根下 | 用 |
| name | 名称 | 用 |

逻辑路径由父子关系拼出，不另存绝对路径。

### 4.3 kb_documents

| 字段 | 说明 | 一期 |
|---|---|---|
| id | 主键 | 用 |
| library_id | 所属库 | 用 |
| folder_id | 所属文件夹，可空=库根 | 用 |
| title | 显示名 | 用 |
| file_name | 原始文件名 | 用 |
| rel_path | 相对 kb/库id 的路径 | 用 |
| source | `upload` / `files_ref` | 一期只写 upload |
| tags | 标签，逗号或 JSON 列表 | 用 |
| file_hash | 内容哈希，查重 | 用 |
| parse_status | `ready` / `no_text` / `failed` / `pending` | 一期：能预览即 ready，否则按类型标 |
| mime_or_kind | pdf / image / text / other | 用 |
| evidence_level | `可概述` / `须出处` / `须原图` | 占位，默认须出处 |
| files_ref | 文件柜引用信息 | 占位 |
| wiki_json | 摘要、是否过期 | 占位 |
| embedding_profile | 向量模型名、维度 | 占位 |
| extra | 扩展袋 | 占位 |
| search_text | 抽出的检索正文 | 二期用 |
| created_at / updated_at | 时间 | 用 |

不建 Wiki 表。四期加 `kb_chunks` 存文本向量，加 `kb_assets` 存抽出的图。

### 4.4 kb_assets

| 字段 | 说明 |
|---|---|
| id | 主键 |
| library_id | 所属库 |
| document_id | 所属资料 |
| rel_path | 相对 kb/库id 的路径；独立图片复用原件路径 |
| page | 页码，docx / 独立图为 0 |
| sort_order | 同一份资料里的顺序 |
| alt_text | 默认图名，如「第2页图1」 |
| ocr_text | 识图结果；关着为空 |

## 5. 接口（一期）

前缀 `/api/v1/kb`。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/libraries` | 库列表 |
| POST | `/libraries` | 新建库 |
| PUT | `/libraries/{id}` | 改名/说明 |
| DELETE | `/libraries/{id}` | 删库（同时删文件夹、记录和磁盘文件） |
| GET | `/libraries/{id}/folders` | 文件夹树 |
| POST | `/libraries/{id}/folders` | 新建文件夹 |
| PUT | `/folders/{id}` | 重命名 |
| DELETE | `/folders/{id}` | 删除（空文件夹或连文件策略：一期仅空文件夹可删，或二次确认后连文件删） |
| GET | `/libraries/{id}/documents` | 列表，可按 folder_id、关键词、标签 |
| POST | `/libraries/{id}/documents` | 上传（multipart） |
| GET | `/documents/{id}` | 详情 |
| PUT | `/documents/{id}` | 改标题、标签、移动文件夹 |
| DELETE | `/documents/{id}` | 删除记录和文件 |
| GET | `/documents/{id}/file` | 预览/下载原件 |
| GET | `/assets/{id}/file` | 出处里的抽出图 |
| GET | `/documents/{id}/assets` | 这份资料抽出的图和识图文字 |
| POST | `/documents/{id}/vision` | 一次认若干张还没认过的图 |
| POST | `/assets/{id}/vision` | 认一张图 |
| PUT | `/assets/{id}` | 人工改正识图文字 |
| POST | `/libraries/{id}/ask` | 当前库提问（关键词 + 可选路径 + 当次风格） |
| PUT | `/libraries/{id}/policy` | 库规则、Wiki 开关 |
| GET | `/libraries/{id}/wikis` | 摘要列表（搜、筛、排、分页） |
| POST | `/documents/{id}/wiki` | 生成摘要 |
| PUT | `/documents/{id}/wiki` | 手写保存摘要 |
| DELETE | `/documents/{id}/wiki` | 删摘要 |

查重：同库同哈希已存在则返回提示，由前端决定取消或仍要另存。

## 7. 后期怎么接（一期只占位）

| 口 | 一期 | 以后 |
|---|---|---|
| source | 只 upload | files_ref 引用文件柜 / SFTP |
| parse_status | 能预览即 ready | OCR、加密 PDF |
| search | 二期：关键词 + 抽出正文 | 以后插向量、Wiki |
| policy_json | 三期：Wiki 开关、回答风格、白话规则 | 路径总开关以后再加 |
| wiki_json | 三期：摘要、哈希、更新时间 | 过期只标不删 |
| embedding_profile | 空 | 模型名+维度，搬家不重算 |
| extra | 空 | 页码、材料组等 |

提问默认：当前库；路径按开关；Wiki 按开关；关路径则整库向量。

## 8. 删除与搬家

- 删库：库记录、子文件夹、文档记录、该库磁盘目录一起删
- 搬家：文件和库都在 `BruceWare` 包内，相对路径有效
- 备份导出带 kb：二期再接入现有 backup，一期不改备份模块
