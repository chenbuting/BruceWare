## 一句话

知识库继续对人核对。Agent 单独一个模块。要查资料时，调用现在知识库这一套检索当工具，不另写检索。

## 两块怎么分

| | 知识库提问 | Agent 模块 |
|---|---|---|
| 谁用 | 人要对答案 | 人要办事 |
| 查库 | 当前库，一次检索再答 | 同一条检索，只读 |
| 查完 | 【确凿】【推断】【缺失】【冲突】 | 可以写稿、调别的工具 |
| 答案性质 | 对证 | 生成稿；库外结果分开写 |

```
要对答案  →  知识库提问页（已有，不改）
要办事    →  Agent 模块（以后做）
Agent 要资料 →  调用现有检索（当前库、关键词 + 向量、问句改写、相邻段）
别的工具查来的 →  和库里原文分开写，不当【确凿】
```

## 必须遵守

- Agent 是新模块，不进知识库提问页
- 查库只读，不改资料
- 不另写一套检索，不跨库，不上网当证据
- 漏段和现在提问一样会漏
- 不把对话记忆自动写成知识库
- 不改衣橱、文件柜
